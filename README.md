# Olamilekan Football

An original football-game starter built for Godot 4.

Features in this starter:
- 11-player squad
- Male fictional footballers
- Player ratings and card tiers
- Countries and positions
- 3D pitch and ball
- Playable match demo
- Passing/shooting input
- Roster/player-card screen
- Online multiplayer and voice-chat integration placeholders

Important:
This project intentionally uses fictional names and original placeholder 3D players.
Do not add real players, club logos, faces, kits, or likenesses for commercial release
without obtaining the appropriate rights/licences.
